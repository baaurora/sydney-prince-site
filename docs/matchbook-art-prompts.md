# ChatGPT prompts: illustrated matchbook art for Version A

Five images for the "What's Happening These Days?" matchbooks on Version A (The Matchbook). Generate them in one ChatGPT conversation so the style stays consistent: paste the **Style brief** first, then each asset prompt one at a time. When an image is right, download it and save it with the filename given, into `assets/img/matchbooks/`. Then ask Claude to wire them in.

---

## 1. Style brief (paste this first)

> I'm making a set of illustrations for a theatre production manager's portfolio website. The theme is a vintage venue matchbook from someone's collection: warm, collected, a little nostalgic, hand-made. I'll ask for 5 images one at a time. Every image must follow this style exactly:
>
> **Medium and line:** Flat hand-drawn illustration, like a gouache or screen-printed 1950s matchbook. A confident ink outline (about 3px at 1000px wide) in near-black `#1F1B18`. The line wobbles slightly, as if drawn by hand with a brush pen. No vector-perfect geometry, no gradients, no 3D rendering, no photorealism, no glossy highlights.
>
> **Palette, use only these colors:** cream `#F6EEDF`, paper white `#FBF6EC`, tomato red `#D9442B`, deep red `#B8381F`, ink `#1F1B18`, striker brown `#8A6A4F`, dark brown `#6E533C`. A single small accent of mustard `#F2A33A` is allowed. Colors are flat fills with a subtle risograph/paper grain texture over everything. Slight misregistration between color and line is welcome.
>
> **Lettering:** Bold, soft, slightly bouncy vintage serif lettering (like Fraunces or Recoleta in a heavy weight). Lettering looks hand-painted, not typeset. All caps unless I say otherwise.
>
> **View:** Straight-on, front orthographic view. No perspective, no tilt, no shadow cast on a background. The subject fills the canvas edge to edge.
>
> **Output:** PNG, exactly the size I give, no border, no mockup, no hands, no table, no background scene, unless I ask for one.
>
> Confirm you understand, then wait for my first image request.

## Tips

- If a result comes back glossy, 3D or too clean, reply: *"Flatter and more hand-drawn: thicker wobbly ink line, flat fills, more paper grain, no shading gradients."*
- If the match heads come back round, reply: *"Make every match head a tall upright oval, about 1:1.8, solid tomato red."*
- If ChatGPT won't letter a real organization's name, ask it to leave a blank banner. We can set the name in the site's own font instead.
- ChatGPT may output a slightly different size. That's fine, as long as the aspect ratio is close.
